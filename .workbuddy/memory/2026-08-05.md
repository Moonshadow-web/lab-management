## 组内培训签到表两处问题修复
- 现象：①编辑培训记录时「培训老师」字段=金子铮，且签到名单自动从人员表预填也含金子铮 → 看起来两个金子铮；②点「打印空白签到表」出来是空白。
- 根因①：签到名单 `onMounted` 无脑预填全部人员，把培训老师本人也列进去了（人员表仅 1 个金子铮，非数据重复）。
- 根因②：SignInSheet 可打印区在 `el-dialog`（fixed 浮层）内，`window.print()` 不渲染 fixed 浮层内容 → 空白。与早前 NewEmployeeTrainPrint 的坑同一类。
- 修复（`frontend/src/views/training/SignInSheet.vue` + `GroupTraining.vue`）：
  - 打印改 `<Teleport to="body">` + `@media print { body > *:not(.print-root){display:none} .print-root{display:block;position:static} }`（照搬 NewEmployeeTrainPrint 已验证方案）；屏显保留格式化预览（打印时隐藏）。
  - 自动填充名单排除 `header.teacher`（培训老师本人不再出现在签到名单）；新增 `savedNames` prop，已保存名单优先加载，手动增删不再因重开记录丢失。
- 部署：vite build 新 chunk `StaffEducation-DK07qPJg.js`；commit `65d10c1`；`_BUILD_MARK=signin-sheet-print-teacher-dedup-2026-08-05`；内网 build mark + chunk 均 200 生效。
- 注：培训老师作为「培训人」仍单独记录在表单头，打印签到表只列参训人员（不含老师本人）。若用户后续要求老师也要在签到表里签名，去掉 excludeTeacher 即可。

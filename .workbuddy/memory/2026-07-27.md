## 到货接收模块改造 + 试剂配送角色（commit b603efd，已推送部署）

### 需求（用户原话要点）
1. 新增收货里搜索试剂要**模糊搜索**
2. 填好的收货单可以**打印**
3. 有**确认接收**按钮，接收人**默认为系统登录人员**
4. **只有确认接收后**才进入实时库存
5. 权限增加角色**试剂配送**：仅能看到货接收界面；只能新建/修改自己建的；不能删除、不能修改他人记录；工作台也不能看

### 后端改动
- `models/reagent_management.py` Receiving 新增 4 字段：`created_by` / `is_confirmed`(默认False) / `confirmed_at` / `confirmed_by`。
- `api/v1/reagent_management.py`：
  - `create_receiving`：**不再建时入库存**，改写 `created_by=当前用户`、`is_confirmed=False`；权限 `require_roles("admin","reagent_manager","reagent_delivery")`（修复原 orphan 的 `lab_technician`）。
  - 新增 `POST /receivings/{id}/confirm`：写入实时库存(累加 ReagentStock)、置 is_confirmed/confirmed_at/confirmed_by；重复确认 400 防重复加库存；接收人空时取当前登录人。
  - 新增 `PUT /receivings/{id}`：编辑收货单；**已确认则 400 不可改**；试剂配送角色仅能改 `created_by==当前用户` 的记录(403)，管理员/试剂管理员可改任意未确认单。
  - `list_receivings` 增加 `confirmed` 筛选；试剂配送角色仅看自己(`created_by==当前用户`)的记录。
- `main.py` 迁移回填：`UPDATE reagent_receivings SET is_confirmed=1 WHERE is_confirmed IS NULL`（旧记录改版前已入库，视为已确认，避免确认时重复加库存）；新列由 `_ensure_missing_columns` 自动补。
- 权限常量：`module_permission.py` 加角色 `reagent_delivery`、模块 `reagent-receivings`(默认 admin/reagent_manager/reagent_delivery)、`ALL_MODULES`；`security.py ROLE_LABELS`、`users.py ROLE_OPTIONS` 均加「试剂配送」。`DEFAULT_MODULE_PERMISSIONS` 里 `reagents` 仍仅 admin/reagent_manager（试剂配送拿不到试剂管理其余页）。

## 排班模块：换班微信推送 + 计划简化 + 早班/连班提醒时机（commit acb69ad，已部署）

### 需求
1. 发起换班申请时，通过**微信(ServerChan)推送**给对方，提醒登录系统确认。
2. 「排班计划」冗余 → 弱化：所有排班自动归属默认计划「主班表」，月视图自动取，前端**移除计划下拉/计划管理 tab**。
3. 换班入口：工作台换班按钮直达 `?tab=month`（默认当月，可选下月）；之前已去掉点排班计划步骤。
4. 提醒时机变更：**早班=前1天11:30**；**连班=前1天11:30 + 当天11:30**。

### 后端改动
- `main.py`：`ensure_scheduling_defaults` 末尾 upsert 默认计划「主班表」(start 2000-01-01 / end 2099-12-31)；`_reminder_scheduler` 拆成 2 个定时点：08:00 跑非班次类(exclude shift_early/shift_continuous)，11:30 只跑班次类(only_categories)。
- `reminder_engine.py`：`_milestones` 早班=`["1_early"]`、连班=`["1_cont","0_cont"]`（字符串里程碑区分前1天/当天）；`_fetch_items` 早班仅 days_left==1、连班 days_left in (1,0)；`_record_send`/`run_reminders` 支持字符串里程碑去重；`run_reminders` 加 `only_categories`/`exclude_categories` 参数。
- `scheduling.py`：新增 `GET /scheduling/default-plan`（返回主班表 id/起止/发热固定人）；`request_swap` 建 Notification 后按 `NotifyRecipient.name==对方` 匹配启用且 wx_uid 非空的接收人，调 `send_serverchan` 推送（try/except 仅记录，不阻断建单）；引用 `FRONTEND_ORIGIN` 拼链接（`/scheduling?tab=myswap`）。
- `diag.py`：`_BUILD_MARK` → `scheduling-swap-wechat-plan-simplify-2026-07-27`。

### 前端改动
- `api/scheduling.js` 加 `getDefaultPlan()`。
- `Dashboard.vue` 换班按钮 `?tab=swap`→`?tab=month`。
- `SchedulingList.vue`：移除「排班计划」tab-pane 及 2 个 plan `<el-select>`；`genDays` 默认 14→30；`onMounted` 先 `await loadDefaultPlan()` 再初始化月份与首次查网格；删 `loadPlanOptions/onPlanChange/planOptions` 及整块 plan CRUD 死代码；`loadGrid/onGenerate/loadMatrix/saveMatrix/submitBatch` 守卫文案改「默认排班计划未就绪」；`selPlan` 由 `getDefaultPlan()` 赋值。

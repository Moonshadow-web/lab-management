## 踩坑：git 索引文件锁（Windows）
- 本环境 `.git/index`、`cloudbaserc.json` 曾被某进程独占锁（读可、写/rename Permission denied），普通 git add/commit 报「unable to write new index file」；tcb CLI 回写 cloudbaserc.json 报 EPERM（但不影响部署提交「submission completed」）。
- 绕过提交：`cp .git/index .git/alt_index`（读锁内文件 OK）→ `GIT_INDEX_FILE=.git/alt_index git add <files>` → `git write-tree` → `git commit-tree <tree> -p HEAD -m ...` → `git update-ref refs/heads/main <commit>` → `git push`。全程不写被锁的 .git/index。
- 锁约数小时后自动释放（后续恢复正常 git add/commit/push；deploy 也无 EPERM）。遇锁先等/或直接用上述 plumbing 方案。
- 注意：plumbing 提交后真实 .git/index 未更新，需 `git reset --mixed HEAD` 同步（工作区不动）。

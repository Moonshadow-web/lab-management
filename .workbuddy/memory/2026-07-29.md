## 文档列表/下载 500 修复（2026-07-29 凌晨，commit 72c6e70）
- **现象**：用户报告"文件档案里现在空的"——文档列表页完全空白。
- **根因1（列表 500）**：`GET /api/v1/documents` 返回 Document 全字段 ORM 对象（无 response_model 约束），FastAPI `jsonable_encoder` 遇到 `data`(LargeBinary 二进制字节) 时调用 `bytes.decode('utf-8')` → 二进制文件（.docx ZIP 头）不是合法 UTF-8 → `UnicodeDecodeError: 0xb5 in position 11` → 整个列表炸 500，前端看到空白。
- **根因2（下载/预览 500）**：`_content_disposition` 把中文文件名直接塞进 HTTP 头 `filename="室内质控月小结_2026年06月_13.docx"` → Starlette/HTTP 头必须是 latin-1 → `UnicodeEncodeError` → 下载 500。
- **修复**：
  1. `list_documents`：`defer(Document.data)` 阻止加载二进制列
  2. `get_document`：改用 query+defer 替代 db.get()
  3. `update/upload/new_version`：`response_model_exclude={"data"}`
  4. `list_versions`：defer+response_model_exclude 双重保险
  5. `_content_disposition`：legacy `filename="..."` 改为 ASCII-safe（中文走 `filename*=UTF-8''...`）
  6. `_BUILD_MARK` = `docs-jsonable-fix-2026-07-27`
- **部署**：`(echo ""; sleep 3; echo "Y") | tcb cloudrun deploy` → 线上验证：列表 total=484 ✅，下载 doc 507 中文名 40KB ✅

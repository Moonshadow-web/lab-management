## 人员继教管理：证书材料预览/下载 500 修复
- 用户反馈：证书材料"无法预览"。
- 排查：预览 `GET /file/{aid}?inline=true` 走后端 `Response` 直出；下载 `inline=false` 走 COS 302 重定向。实测下载 200、预览 500，且路由修好后返回 `{"detail":"Internal Server Error"}` —— 根因为 `Content-Disposition: inline; filename="中文名.jpg"` 含非 ASCII，Starlette 设响应头时 `UnicodeEncodeError` → 500。
- 前置 bug 也一并修：① 附件路由区 `GET /{owner_type}/{owner_id}`（列表）注册在 `GET /file/{aid}` 之前，Starlette 按注册顺序匹配，导致 `/file/{aid}` 被列表路由抢走返回 `{"items":[],"total":0}`（预览/下载拿不到文件）；已把 `get_attachment` 移到 `list_attachments` 之前。② 文件名改 RFC 5987 编码 `filename*=UTF-8''<percent-encoded>`。
- 部署 `_BUILD_MARK=edu-attachment-preview-utf8-2026-07-31`；验证 `GET /file/1` 返回 200 + 436KB 真实 JPEG（FFD8FF JFIF 头）。下载本就正常（COS 302 不带中文头）。

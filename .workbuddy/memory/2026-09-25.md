### 【重要修复】打印签到表串页：一次打出多张表
**用户实测证据**：在「科内培训」点「打印空白签到表」，打印预览第一页却是**实习生讲课签到表**，左上角"总页数：3 张"。上一轮我看到用户截图里的**屏显预览**是科内版式（BG-KS-PX-807），就断言"不是实习表"——**结论错误，是我误判**（屏显 ≠ 打印输出）。
- **根因**：`SignInSheet`（组内 sm / 科内 ks）与 `InternLecture` 的打印副本都用 `Teleport to="body"` 挂载，print CSS 只写了 `body > *:not(.print-root){display:none}` + `.print-root{display:block}` —— **凡是已经挂载过、常驻 body 的 print-root 会全部一起输出**。element-plus 的 `el-tab-pane` 渲染后不销毁，用户一旦进过「实习进修带教 → 讲课计划」，该组件的 print-root 就一直在 body 上 → 打印时它先出（DOM 顺序靠后/靠前），于是"科内培训"打出实习表，且总计 3 张。
- **修法**：给打印副本加唯一标识 class（`pr-sm` / `pr-ks` / `pr-il`），点打印时设 `document.body.dataset.printTarget='sm'|'ks'|'il'`，CSS 改为
  `body[data-print-target] > .print-root{display:none!important}` +
  `body[data-print-target="ks"] > .print-root.pr-ks{display:block!important}`（其余同理）。
  **注意两点**：① 规则必须加 `[data-print-target]` 前置条件，否则会把 `CompetencyAssessmentPrint` / `NewEmployeeTrainPrint` 这两个 `v-if` 打印组件一起隐藏掉；② `window.print()` 之后 `delete document.body.dataset.printTarget` **复位**，避免残留标记影响后续其它组件的打印。
- commit `9d434ca7`，build mark `print-single-target-2026-09-25`；验证线上 chunk 含 `pr-ks` / `pr-il` / `printTarget`。
- **教训**：涉及打印的功能，必须**以实际打印预览为准**验证（屏显预览正常不代表打印正常）；本项目所有 `print-root` 都 Teleport 到 body，**多组件并存时必然串页**，新增打印组件一律要走这套 target 标记。

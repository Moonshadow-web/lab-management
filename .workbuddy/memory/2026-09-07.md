## LJ 质控图「点查看不生成」三层根因修复（2026-09-07 深夜）
- 现象：质控管理 → LJ 质控图，选齐年月/仪器/项目点「查看质控图」无任何反应（无图、无报错）。
- 排查：后端 `/qc-summaries/daily/project` 实测正常（2026-08/仪器5/Apo-A 返回 31 行），echarts 6.1.0 已打包进共享 chunk `index-DgQRkS4v.js` 且导出 init —— 数据与依赖都没问题，问题纯前端。
- **三层根因（逐层剥出）**：
  1. `el-tab-pane` 用了 `v-for="tab in visibleTabs"`，pane 内的 `template v-if="activeTab==='chart'"` **对每个 pane 实例求值** → `.chart-box` 渲染了 **6 份**（每个 tab 一份），浏览器实测 6 个 box 仅激活 pane 那份 480×560 可见，其余 5 份 display:none 尺寸 0。
  2. `chartRef` 因此被 Vue 绑成**数组**；原代码 `echarts.init(chartRef.value)` 把数组整个传进去抛 TypeError，而 `import('echarts').then(...)` **没有 .catch** → 错误被 Promise 静默吞掉 = "点了没反应"。
  3. 第一版修复（`getChartEl` 取 `r[0]`）不彻底：`r[0]` 是"室内质控月结"pane 里那份隐藏 div → 图画在隐藏元素上，canvas 退化成 100px 窄条，用户看到的区域仍空白。
- **最终修复**（QCList.vue）：
  - `getChartEl()`：从数组中取 `el.offsetParent !== null`（可见）的那份 —— 这是唯一正确目标。
  - `import('echarts')` 加 `.catch` → `ElMessage.error('质控图渲染失败：...')`，兼容 `mod.default||mod`。
  - init 后挂 `ResizeObserver` + `requestAnimationFrame` 强制 resize（flex/tab 布局晚于 init 时防窄条），disposeChart 时断开 observer。
  - 数据为空时 `ElMessage.warning('该项目在当前月份没有每日质控数据…')`。
- **浏览器实测闭环**（agent-browser 登录线上）：2026-08 + AU5800急诊 + 总蛋白(水平1/2) → 可见 chart-box canvas **480×560**，SDI 模式图完整（双水平线、3SD 失控限红/2SD 警告限黄、截止点、副标题靶值 SD）。提交 efafbc4（前置 6696f88/ccb4ad8），线上 chunk `QCList-DcI0ge8j.js` 200 含 offsetParent。
- **结构性教训（本项目级）**：该页面所有 tab 内容都写在 v-for 的单个 pane 内、靠 template v-if 切换 → **每个 tab 的模板在每个 pane 里都渲染一份**。任何 template ref 在此页面都会拿到"6 份元素的数组"；同文件 csvInput 的旧注释（`Array.isArray(x)?x[0]:x`）只对了一半 —— 还必须按**可见性**挑元素，否则拿到的是隐藏 pane 的。后续此页面新增 ref 一律走 `offsetParent` 过滤。

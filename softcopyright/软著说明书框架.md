## 件① 检验科生化免疫组检验项目与仪器管理软件

**1. 软件概述**
面向检验科生化免疫专业组的检验项目主数据与仪器档案管理工具，管理 560+ 检验项目、仪器台账、仪器家族、仪器技术档案与仪器相关文档，支撑 ISO 15189 受控管理。

**2. 功能模块**
- 检验项目管理：项目增删改查、批量导入、参考区间、方法学、单位主数据
- 仪器管理：仪器台账、状态、检定/校准周期提醒
- 仪器家族管理：同型号多台仪器的家族归组
- 仪器档案管理：SOP、检定证书、维护记录附件
- 仪器文档关联：文档与仪器的挂载

**3. 操作流程**
登录系统 → 进入"检验项目/仪器"模块 → 录入或导入项目/仪器信息 → 上传技术档案 → 查询与维护。

## 件② 检验科生化免疫组室间质评与比对管理软件

**1. 软件概述**
管理室间质评（EQA）计划、成绩、总结自动生成，以及仪器间比对（WS/T 403—2024）、室间比对（WS/T 415）、多源质量目标综合比对，解决质评上报准确性与比对判定一致性。

**2. 功能模块**
- EQA 计划/成绩管理、单位自动换算校正、报告正文解析、总结(CZ-020)自动生成
- 项目-计划别名消歧关联
- 仪器间比对：偏倚计算 + 允许总误差(WS/T 403)判定
- 室间比对：定量偏倚+4/5通过、定性符合率（WS/T 415）
- 质量目标：WS/T403 + 北京 HR + NCCL 三源同表比对

**3. 操作流程**
登录 → 进入"质评/比对"模块 → 建立计划/录入结果 → 系统自动换算/判定 → 生成总结报告。

## 件③ 检验科生化免疫组室内质控与靶值管理软件

**1. 软件概述**
室内质控日常值管理、Westgard 多规则协同判定（含跨水平 SD 归一化 R-4s、多源规则冲突消解）、质控品靶值累计（即刻法→常规法）、月结报告自动草拟。

**2. 功能模块**
- 质控日常值录入/导入、失控标记
- Westgard 多规则判定引擎（13S/22S/R4S/10x/12S 及冻结语义）
- 质控品靶值累计（即刻法 + SI 界值表，n=20 转常规法）
- 月结汇总与 CZ-012 报告草拟

**3. 操作流程**
登录 → 进入"质控"模块 → 录入每日质控值 → 系统自动判定失控 → 查看月结。

## 件④ 检验科生化免疫组试剂与物料管理软件

**1. 软件概述**
试剂目录、库存、盘库、订购、到货接收（确认后入库）、月消耗核算，支撑试剂成本与效期管理。

**2. 功能模块**
- 试剂目录（含类型自动识别、Excel 导入去重）
- 库存管理（数量、效期、预警）
- 盘库（期末盘点）
- 订购单
- 到货接收（到货确认才入库，权限隔离）
- 月消耗核算（消耗 = 期初 + 入库 − 期末）

**3. 操作流程**
登录 → 进入"试剂"模块 → 维护目录/库存 → 盘库 → 生成订购 → 到货确认。
